**Goal**

Create a single source of truth for team health, project velocity, and customer signals. The system needed to feel fast, approachable, and extensible.

**Highlights**

- Designed a streaming ingestion pipeline to keep dashboards live.
- Built a metrics schema that normalized data from multiple sources.
- Shipped a focused UI that let teams answer questions in seconds.

**Outcome**

Teams reduced time spent generating reports by 40% and adopted the dashboard in weekly planning sessions.
